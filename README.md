# NRO Termux

Tool hỗ trợ chạy và quản lý script NRO trên Termux bằng Python.

## 📌 Tính năng
- Menu giao diện CLI đẹp
- Quản lý account
- Kết nối MySQL
- Hỗ trợ API
- Chạy trên Termux Android
- Hỗ trợ màu terminal
- Tối ưu cho Python 3
